## Content of a RESUME 

1. Full Name
2. Contact Information
3. Social media links
4. Summary
5. Skills
6. Experience
7. Projects ( if applicable )
8. Achievements (optional)
9. Education 
 
## What to Include 

1. Full Name
   - preferred name
   - Under it, optionally put your target role
     
2. Contact Information
    - Phone number
    - Professional email
    - City, State, India
    - LinkedIn
  
      
3. Summary
   - Who you are +
   - what you specialize in +
   - what you've built +
   - what role you're targeting.
     
4. Experience
   - If you have formal employment/internship experience:
   ```txt
     Company | Role | Location
     Month
      Year – Month Year
     ```
   - Use
     ```txt
     Action + technology + what you accomplished + measurable result
     ```

5. Projects
   - ```txt
     Project Name | GitHub | Live Demo
     Tech stack
     ```
   - 2–4 strong bullet points.
   - ```txt
     Problem → Architecture/technical approach → Your contribution → Result
     ```

6. Skills
   - Organize skills by category
  
7. Achievements
   > Only include achievements that create evidence of capability.

   - Good
     
     1. Hackathon finalist/winner
     2. Competitive programming rating/rank
     3. Open-source contributions
     4. Technical competition
     5. Scholarship based on merit
     6. Research/publication
     7. Significant project adoption/users
     8. Coding contest rankings 

   - Weak
   
     1. “Completed Python course”
     2. “Watched 100 hours of coding tutorials”
     3. “Certificate of participation” 

 8. Education
    - University/institute Name
    - Grade/CGPA ( Optional )

     > You don't need to list every school subject or every semester's marks.


## Recommendations

- For Freshers
```txt
 Name → Contact → Summary → Skills → Projects → Experience → Achievements → Education
  ```
- A strong one-page resume with 2 excellent projects beats a crowded two-page resume
